# Rohan Sonkar - Portfolio

A starter personal portfolio website built with HTML, CSS and JavaScript.

## Files

- `index.html` - Home page
- `about.html` - About page
- `contact.html` - Contact page
- `style.css` - Website styling
- `script.js` - JavaScript
- `images/` - Placeholder images
- `assets/resume.pdf` - Placeholder resume file

## Before publishing

Replace the placeholder profile/project images, resume, email address, and About text with your real information.

## Run locally

Open `index.html` in a browser.
